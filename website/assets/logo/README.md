# Logo assets

Official Bean and Bear logo artwork, cropped to tight bounding boxes (viewBox only — path
data untouched) from the brand's source files. Wordmark is "BEAN AND BEAR" (capitalised),
set in Cormorant Garamond with a small-caps "AND" underline, matching the pot labels in
`assets/img/flavours/`.

- `icon-*` — the walking-bear mark alone.
- `wordmark-only-*` — "BEAN AND BEAR" text alone, no "GELATO" line.
- `wordmark-gelato-*` — "BEAN AND BEAR" with the "GELATO" subtitle beneath.
- `full-lockup-white.svg` — icon + wordmark + "GELATO", stacked, as used on the live site.

Suffix is the background: `-dark` (forest `#0F2D23`), `-cream` (`#F7F1E6`), `-white`.
`-transparent` variants have the background rect stripped, for placing directly on an
existing coloured surface (e.g. the iPad prototype's sidebar gradient) rather than a flat
tile.
