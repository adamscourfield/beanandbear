A single, self-contained page to put live now, while the full site is in
progress. Vanilla HTML and CSS, no JavaScript, no dependencies.

Open bean-and-bear-coming-soon.html directly, or host index.html +
styles.css + assets/ together.

the gold bear, the \"Bean and Bear Gelato\" lockup, \"Opening soon.\"

email notify form (not wired to anything), and X / Instagram icons and
the [[hi@beanandbear.com]{.underline}](mailto:hi@beanandbear.com)
contact link.
