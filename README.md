# Bean and Bear

Source for the Bean and Bear Gelato website.

- **`coming-soon/`** — the single page currently live at [beanandbear.uk](https://beanandbear.uk): a shopfront photo, the logo, an email notify form, and social links. No JavaScript.
- **`website/`** — the full site (home + shop, 42 flavours, account/basket/flavour detail as CSS-only sheets), built from the brand book, not yet live. `index.html` + `styles.css` + `assets/` is the deployable version; `bean-and-bear-website.html` is the same site packaged as a single self-contained file. See `website/README.md` for how it's built, and `website/PHOTO_BRIEF.md` / `website/PHOTO_FIXES.md` for outstanding photography work.

Both sites are vanilla HTML and CSS with no build step and no JavaScript dependencies.
